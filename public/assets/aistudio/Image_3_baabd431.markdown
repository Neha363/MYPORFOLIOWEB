## Brand & Style

The design system projects high-caliber technical competence, intellectual curiosity, and modern engineering polish for an AI/ML developer portfolio. It speaks directly to recruiters, engineering managers, tech leads, and open-source collaborators who seek exceptional craftsmanship and rigorous systems thinking.

### Design Movement: Deep Space Glassmorphism & Cyber Minimalism
The visual language merges the sleek refinement of modern developer tools with futuristic AI/cyber touches:
- **Atmospheric Space:** Dominant void-black and deep-slate canvas surfaces that eliminate ocular fatigue and provide infinite depth.
- **Controlled Luminescence:** Restrained electric cyan and ultraviolet glows acting as directional highlights, focal anchors, and state signifiers rather than indiscriminate decor.
- **Glassmorphic Precision:** Translucent layered panels with microscopic light borders (`rgba(255, 255, 255, 0.08)`), multi-tier background blurs, and surface gradients that elevate flat UI into dimensional planes.
- **Tactile Code Ergonomics:** Crisp monospaced and high-legibility geometric sans-serif typography paired with pill badges, telemetry indicators, and interactive laser accents.

## Colors

The palette simulates a deep space workstation cockpit: rich dark foundations illuminated by high-energy optical accents.

### Palette Architecture
- **Primary (`#38BDF8` - Electric Cyan / Sky):** Represents computation, data streams, active link interactions, and high-priority states. Used for primary focus rings and terminal-grade highlights.
- **Secondary (`#8B5CF6` - Neural Violet):** Represents AI architectures, intelligence pipelines, and secondary highlights. Blends with Primary to form signature linear gradients across key headlines and hero elements.
- **Tertiary (`#2563EB` - Hyper Cobalt):** Deep supportive electric blue for button foundation gradients, deep shadows, and active structural backings.
- **Neutral Canvas (`#0B0F19` - Space Void):** Absolute background depth.
- **Neutral Surface (`#0F172A` - Slate Deck):** Component, section, and card background color.

### Functional Grayscale & Translucency
- **Surface Elevation 1:** `rgba(15, 23, 42, 0.65)` with `backdrop-filter: blur(16px)`
- **Surface Elevation 2:** `rgba(30, 41, 59, 0.7)` with `backdrop-filter: blur(24px)`
- **Border Default:** `rgba(255, 255, 255, 0.08)`
- **Border Hover / Active:** `rgba(56, 189, 248, 0.4)`
- **Text High-Contrast:** `#F8FAFC`
- **Text Body / Muted:** `#94A3B8`
- **Text De-emphasized:** `#64748B`

## Typography

The typographic hierarchy utilizes three distinct typefaces to convey distinct tiers of authority:
1. **Plus Jakarta Sans (Headings & Display):** Modern, geometric, clean-cut structural presence. It offers punchy impact for hero copy, project titles, and section dividers without visual clutter.
2. **Inter (Body & Content):** Pure utilitarian legibility engineered specifically for low-fatigue reading on screens. Neutral and unpretentious for long-form case studies, project narratives, and technical breakdowns.
3. **JetBrains Mono (Metadata, Badges, Metrics & Code):** Authentic developer DNA. Used for tech stack badges, timestamp metadata, model benchmarks, floating telemetry, and code blocks.

### Typography Rules
- Pair gradient fills (`linear-gradient(135deg, #F8FAFC 0%, #38BDF8 60%, #8B5CF6 100%)`) with `display` and `headline-lg` styles for signature statements.
- Avoid all-caps usage on `Plus Jakarta Sans` or `Inter`. Reserve uppercase treatment strictly for `label-sm` in `JetBrains Mono` when designating system statuses or skill categories.

## Layout & Spacing

The layout philosophy uses a disciplined 12-column grid anchored by an 8pt spatial rhythmic baseline.

### Grid Architecture
- **Desktop (≥ 1280px):** 12-column fluid grid, max-width `1280px`, outer margins `space-3xl` (`5rem`), gutters `gutter` (`1.5rem`).
- **Tablet (768px – 1279px):** 8-column fluid grid, outer margins `space-xl` (`2.5rem`), gutters `gutter` (`1.5rem`).
- **Mobile (≤ 767px):** 4-column fluid grid, outer margins `margin-mobile` (`1.25rem`), gutters `gutter-mobile` (`1rem`).

### Content Sectioning
- Section-to-section vertical separation must maintain `space-3xl` (`6rem`) on desktop and `space-2xl` (`4rem`) on mobile to establish clear breathing room and focus.
- Component-level rhythm relies on `space-xs` (tags/badges internal padding), `space-sm` (icon-to-text spacing), `space-md` (card item gaps), and `space-xl` (card internal padding).

## Elevation & Depth

Visual hierarchy does not use simulated skeuomorphic drop shadows. Instead, it relies on an optical physics model blending glassmorphism, translucency tiers, and directional neon glows.

### Elevation Levels

#### Ground Zero (Canvas)
- Flat solid `#0B0F19` with subtle radial gradient backdrops: `radial-gradient(circle at 50% 0%, rgba(56, 189, 248, 0.08) 0%, rgba(139, 92, 246, 0.03) 40%, transparent 70%)`.

#### Level 1 (Resting Cards, Bento Containers)
- **Background:** `rgba(15, 23, 42, 0.6)`
- **Backdrop Blur:** `blur(16px)`
- **Border:** `1px solid rgba(255, 255, 255, 0.08)`
- **Shadow:** `0 4px 20px -2px rgba(0, 0, 0, 0.5)`

#### Level 2 (Hovered Cards, Dropdowns, Floating Navbars)
- **Background:** `rgba(30, 41, 59, 0.75)`
- **Backdrop Blur:** `blur(24px)`
- **Border:** `1px solid rgba(56, 189, 248, 0.35)`
- **Shadow:** `0 12px 32px -4px rgba(0, 0, 0, 0.7), 0 0 24px -2px rgba(56, 189, 248, 0.15)`

#### Level 3 (Modals, Overlays, Active Key Features)
- **Background:** `rgba(15, 23, 42, 0.92)`
- **Backdrop Blur:** `blur(32px)`
- **Border:** `1px solid rgba(139, 92, 246, 0.45)`
- **Shadow:** `0 24px 48px -8px rgba(0, 0, 0, 0.8), 0 0 32px 0px rgba(139, 92, 246, 0.2)`

### Neon Cyber Glows
- Glowing interactive elements combine a sharp outer border highlight with a soft feathered outer glow: `box-shadow: 0 0 16px rgba(56, 189, 248, 0.35), inset 0 0 12px rgba(56, 189, 248, 0.1)`.

## Shapes

The design system employs a Level 2 (`Rounded`) geometric foundation, balancing modern UI software conventions with engineered sharpness.

### Geometry Hierarchy
- **Base Components (Inputs, Buttons, Default Cards):** `0.5rem` (`8px`) to `0.75rem` (`12px`).
- **Feature Cards & Bento Grids (`rounded-lg` / `rounded-xl`):** `1rem` (`16px`) to `1.5rem` (`24px`).
- **Pill Badges, Chips & Status Dots:** Fully rounded (`9999px`) to emphasize modularity and capsule ergonomics.
- **Glass Card Inset Borders:** Always follow the concentric outer border radius minus the padding distance.
